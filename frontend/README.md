# /frontend — Minimalist Next.js User Interface

Clean, minimalist user interface built with Next.js and Tailwind CSS:

- **Single Upload Zone**: Drag-and-drop support for 1 or 2 satellite images (GeoTIFF/TIFF/PNG), auto-detecting single-image vs. paired modes.
- **Natural Language Query Box**: Interactive text prompt input.
- **Unified Result Panel**:
  - Direct answer text.
  - Evidence visualization (bounding boxes, change mask overlays, false-color composites).
  - Normalized confidence score badge.
  - Collapsible Auditable Execution Trace accordion.
  - One-click "Download PDF Report" action.
